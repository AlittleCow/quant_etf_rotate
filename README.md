# 二八轮动 ETF 量化策略回测

基于 ETF 动量轮动的量化策略复现项目：每月末比较沪深 300 与中证 500 的动量，强者持有、弱者或均弱时切换至国债 ETF 防守，实现「牛市持股、震荡/熊市持债」的动态配置。

---

## 1. 策略简介

### 1.1 二八轮动原理

「二八轮动」是国内经典的 ETF 轮动策略：在**大盘（沪深 300）**与**小盘（中证 500）**之间比较相对强弱，只在趋势明确时持有股票类资产，趋势不明或走弱时转入**国债 ETF** 防守，从而规避系统性下跌风险。

本项目以三只 ETF 作为标的：

| 代码 | 名称 | 角色 |
|------|------|------|
| 510300 | 沪深 300 ETF | 大盘权益 |
| 510500 | 中证 500 ETF | 小盘权益 |
| 511010 | 国债 ETF | 防守资产 |

### 1.2 策略规则

1. **信号计算**：每个交易日计算各资产近 20 个交易日的动量（`pct_change(20)`）。
2. **月度调仓**：每月最后一个交易日生成信号，确定下月首个交易日应持有的标的：
   - 在沪深 300 与中证 500 中选出动量最大者；
   - 若该动量 > 阈值（默认 0.02），则持有该权益 ETF；
   - 否则持有国债 ETF（防守）。
3. **空值处理**：停牌导致的动量缺失，先用前一交易日的动量补齐，仍缺失则视为「不可交易」，不选为目标。
4. **成本假设**：单边交易费率 0.1%，调仓日按双边（2×fee）计成本。

## 2. 回测结果

回测区间 **2015-01-01 至 2026-06-01**，结果如下（由 `src/research.py` 与 `src/backtest.py` 计算并绘图）：

| 策略           | 累计净值      | 年化收益    | 夏普比率 | 最大回撤 |
|--------------- |-------------|-----------|---------|---------|
| **二八轮动策略** | **2.604**   | **9.1%** | **0.45** | **-40.2%** |
| 一直持有沪深 300 | 1.685       | 4.9%      | 0.24     | -53.0% |
| 一直持有中证 500 | 1.902       | 6.0%      | 0.28     | -65.8% |

默认参数（rotate=20、threshold=0.02）下：策略年化 9.1%、夏普 0.45，跑赢买入持有，最大回撤显著收窄。
但需注意参数敏感性,对 `threshold`（0~0.1）共20组组合做扫描后，大部分参数不能获得如此高的收益；且默认参数恰好是全局最优（年化利率9.1%），存在参数挑选的嫌疑。策略真正稳健的价值在于**回撤控制**——绝大多数参数下最大回撤远小于大盘的 -53%。

净值对比与仓位结构图见 `output/Figure_*.png`。

## 4. 运行代码

### 4.1 环境配置

在项目根目录下依次执行（需将 conda 配置到环境变量）：

```bash
conda env create -f environment.yml   # 创建环境
pip install -r requirements.txt       # 安装依赖
conda activate quant                  # 激活环境
```

### 4.2 完整流程

1. **抓取数据**（需 tushare token，见第 5 节说明）：

```bash
python src/data/fetch_raw_etf.py
```

2. **清洗入库**：

```bash
python src/data/data_cleaning.py
```

3. **运行回测**（输出绩效指标）：

```bash
python src/backtest.py
```

4. **绘制净值对比与仓位结构图**：

```bash
python src/research.py
```

## 5. 数据来源与参考

- **ETF 日线数据**：使用 akshare 的 `fund_etf_hist_em` 接口获取，采用**前复权**价格（`adjust="qfq"`）。
- **交易日历**：使用 tushare 的 `trade_cal` 接口获取。
- 特别说明：
  - `src/data/fetch_raw_etf.py` 第 74 行需设置 tushare 的 token，否则会报错；如无 token 请联系项目作者。
  - 经排查，中证 ETF 因调整基金份额于 2015-04-13 与 2015-04-14 停牌，策略已通过空值处理跳过。
